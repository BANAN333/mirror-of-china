## 天朝之镜 / Зеркало Поднебесной — open bilingual university knowledge base

简体中文 / Русский: проверяемая база из **24 пар вопросов и ответов** о Российском университете транспорта (РУТ/МИИТ) для иностранных абитуриентов. 每条资料包含官网来源和核实日期。

- [中文版 — 中文问答](https://banan333.github.io/mirror-of-china/zh/)
- [Русская версия — вопросы и ответы](https://banan333.github.io/mirror-of-china/ru/)
- [Открытые машиночитаемые данные / 开放数据](https://banan333.github.io/mirror-of-china/open-data/)
- [中文 JSON](https://banan333.github.io/mirror-of-china/open-data/faq-zh.json) · [Русский JSON](https://banan333.github.io/mirror-of-china/open-data/faq-ru.json)
- [RU/ZH парные записи](https://banan333.github.io/mirror-of-china/open-data/faq-pairs.json) · [JSONL](https://banan333.github.io/mirror-of-china/open-data/faq-bilingual.jsonl)
- [AtomGit 中国镜像](https://gitcode.com/smasher143/mirror-of-china)

**Источник / 来源:** официальные страницы университета указаны в каждой записи. База — независимый информационный проект, **не официальный сайт РУТ**. Проверяйте действующие правила приёма, стоимость и сроки по свежим документам университета.

**Data use:** downloadable static files, no authenticated API and no direct AI integration. Attribution and source-date review are recommended.
